# Data

This directory contains the input datasets, prepared data products, and selected derived files used by the reproducibility workflow for:

> **Reconstructing East Asian Temperatures from 1368 to 1911 Using Historical Documents, Climate Models, and Data Assimilation**

The main computational workflow is executed from the repository root using:

```bash
REPRODUCTION_MODE=full \
Rscript --vanilla run_all.R
```

Most intermediate products generated by the workflow are written under:

```text
Output/Intermediate/
```

The `Data/` directory primarily contains the datasets required to start the analysis and selected derived files used by downstream scripts.

## Directory Organization

```text
Data/
├── Get_data/                      Upstream data-preparation documentation and scripts
├── LME data/                      Prepared LME ensemble-member files
├── Population/                    Historical population raster data
├── REACHES/                       Repository-supplied REACHES-related data products
├── Valid/                         City-specific assimilation files used for validation
├── par/                           Reference city-specific prior-parameter estimates
├── GHCNv4.xlsx                    GHCN instrumental temperature data
├── temperature index value.v1.xlsx
└── README.md
```

## Reproducibility Input Boundary

The distributed reproducibility workflow begins with the prepared data files contained in this directory.

In particular, the LME workflow begins with:

```text
Data/LME data/a1.csv.gz
Data/LME data/a2.csv.gz
...
Data/LME data/a13.csv.gz
```

The original LME NetCDF files are not redistributed in this repository because of their size. The optional upstream conversion script is retained under:

```text
Data/Get_data/GetLME.R
```

This script documents the conversion from the original NetCDF files to the prepared gzip-compressed member files, but it is not called by the default `run_all.R` workflow.

## 1. REACHES Documentary Temperature Data

The main REACHES source file is:

```text
Data/temperature index value.v1.xlsx
```

The analysis scripts extract the documentary temperature level, calendar year, longitude, and latitude from this workbook.

This file is used by several parts of the analysis, including:

- Figure 2;
- calibration of the interval-censored covariance model;
- interval-censored kriging;
- Figure 5;
- Figure S1;
- the documentary-coverage and population analysis; and
- the held-out interval-compatibility validation.

The documentary temperature index is an ordinal, dimensionless quantity. Missing values are represented as `NA` after import into R.

The directory:

```text
Data/REACHES/
```

contains repository-supplied REACHES-related files retained for reference or precomputed use.

The full workflow regenerates the primary kriging products under:

```text
Output/Intermediate/REACHES/
```

Important regenerated files include:

```text
Output/Intermediate/REACHES/reaches_kriging_lme_grid_mean.csv
Output/Intermediate/REACHES/reaches_kriging_city3_mean.csv
Output/Intermediate/REACHES/reaches_kriging_city3_sd.csv
Output/Intermediate/REACHES/reaches_kriging_city3_metadata.csv
Output/Intermediate/REACHES/reaches_kriging_metadata.csv
```

The file:

```text
reaches_kriging_city3_sd.csv
```

contains prediction standard deviations. The underlying prediction variance or mean-square prediction error is handled separately in the kriging and assimilation calculations.

```text

a12.csv.gz

```

These files are the starting point for:

```text
Code/DataPreparation/prepare_lme_annual.R
```

The preparation script:

- reads the 13 ensemble-member files;
- constructs annual temperature fields for 1368–1911;
- converts temperature from Kelvin to degrees Celsius where required;
- calculates the LME ensemble mean;
- spatially interpolates the LME fields to the three nominal GHCN station coordinates; and
- saves the resulting annual and city-specific products under `Output/Intermediate/LME/`.

Important regenerated LME files include:

```text
Output/Intermediate/LME/lme_annual_1368_1911.rds
Output/Intermediate/LME/lme_city3_annual_1368_1911.csv
Output/Intermediate/LME/lme_ensemble_mean_1368_1911.csv
```

The default reproducibility workflow does not require the original NetCDF files.

Further information about the optional upstream NetCDF conversion is provided in:

```text
Data/Get_data/README.md
```

## 3. GHCN Instrumental Temperature Data

The GHCN data used for instrumental validation are stored in:

```text
Data/GHCNv4.xlsx
```

This file is used by:

```text
Code/Figure10.R
```

The city-specific REACHES, LME, assimilation, and GHCN analyses use the following nominal GHCN station coordinates:

| City | Longitude | Latitude |
|---|---:|---:|
| Beijing | 116.283 | 39.933 |
| Shanghai | 121.433 | 31.167 |
| Hong Kong | 114.167 | 22.333 |

Longitude and latitude are expressed in decimal degrees east and north, respectively.

The REACHES predictions are kriged directly at these coordinates. The LME temperature fields are spatially interpolated to the same nominal coordinates.

## 4. Historical Population Data

Historical population data are stored under:

```text
Data/Population/
```

These data are used by:

```text
Code/Analysis/coverage_population_GAM.R
```

for the documentary-coverage and historical-population analysis in Section 5.1.

The analysis uses historical population rasters corresponding to the available population reference years, including:

```text
1776
1820
1851
1880
1910
1953
```

The population values are spatially associated with the LME analysis grid and are used to construct the historical population covariate in the generalized additive models.

The workflow writes the corresponding model summaries and tables under:

```text
Output/Tables/
```

including:

```text
Output/Tables/Table2_coverage_GAM.csv
Output/Tables/Table2_Hgu_coefficient.csv
Output/Tables/TableS2_M4_parametric_coefficients.csv

```

## 5. City-Specific Prior-Parameter Files

The directory:

```text
Data/par/
```

contains reference or precomputed city-specific prior-parameter estimates.

The file prefixes correspond to the parameters:

```text
mt
mu
rt
```

The final character identifies the city:

| Character | City |
|---|---|
| `B` | Beijing |
| `S` | Shanghai |
| `H` | Hong Kong |

For example:

```text
Data/par/mtB.csv
Data/par/muB.csv
Data/par/rtB.csv

Data/par/mtS.csv
Data/par/muS.csv
Data/par/rtS.csv

Data/par/mtH.csv
Data/par/muH.csv
Data/par/rtH.csv
```

The full reproducibility workflow regenerates the city-specific prior estimates using:

```text
Code/Prior.R
```

and writes the regenerated files under:

```text
Output/Intermediate/Prior/
```

The full manuscript analysis uses the complete penalty-parameter search grid.

An optional smoke-test mode uses a reduced search grid only to verify that the end-to-end workflow executes successfully.

## 6. City-Specific Assimilation and Validation Files

The directory:

```text
Data/Valid/
```

contains the city-specific assimilation files used by downstream validation and supplementary-figure scripts:

```text
Data/Valid/assimilation_Beijing.csv
Data/Valid/assimilation_Shanghai.csv
Data/Valid/assimilation_HongKong.csv
```

These files are generated by:

```text
Code/Figure9d.R
```

and are used by:

```text
Code/Figure10.R
Code/Supplementary/FigureS2.R
```

Each city-specific file contains annual assimilation quantities such as:

- calibrated REACHES temperature;
- effective proxy temperature;
- dynamic prior prediction;
- filtered temperature;
- smoothed temperature;
- LME ensemble-mean temperature;
- filtered and smoothed uncertainty;
- measurement-equation parameters;
- Kalman observation weight; and
- numerical diagnostic quantities.

The exact variables are documented in the project data dictionary.

## 8. Units and Missing-Value Conventions

Unless otherwise specified:

| Quantity | Unit or convention |
|---|---|
| Calendar year | Common Era year |
| Longitude | Decimal degrees east |
| Latitude | Decimal degrees north |
| REACHES documentary level | Dimensionless ordinal index |
| LME temperature input | Kelvin where applicable |
| Processed LME temperature | Degrees Celsius |
| Calibrated REACHES temperature | Degrees Celsius |
| Assimilated temperature | Degrees Celsius |
| Variance or MSPE | Squared units |
| Standard deviation | Original units |
| Missing values | `NA` |

Prediction variance and prediction standard deviation are treated as distinct quantities throughout the kriging, quantile-mapping, and assimilation workflows.
